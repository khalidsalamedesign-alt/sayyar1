# سيّار — SAYYAR

منصة سورية لبيع وشراء الآليات المستعملة: سيارات، فانات ونقل خفيف، وموتسكلات، من أفراد ومعارض موثّقة.

هذا المستودع يحتوي **النماذج الأولية للواجهة (Prototype)** وهوية الشعار، قبل بناء الموقع الفعلي بـ Next.js و Supabase.

## المحتويات

```
brand/      هوية الشعار: صفحة دليل الشعار، الرمز SVG، أيقونة التطبيق، ومتغيرات الألوان
design/     صفحات الموقع (HTML/CSS/JS بدون مكتبات)
serve.py    خادم معاينة محلي يمنع الحفظ المؤقت ويفتح من الموبايل
```

### صفحات `design/`

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` |
| نتائج البحث والفلاتر | `search.html` |
| تفاصيل الإعلان | `listing.html` |
| نشر إعلان (6 خطوات) | `post.html` |
| الدخول والتسجيل | `auth.html` |
| دليل المعارض | `dealers.html` |
| صفحة المعرض | `dealer.html` |
| باقات المعارض والدفع اليدوي | `plans.html` |
| لوحة المستخدم | `account.html` |
| لوحة المعرض | `dealer-dashboard.html` |
| لوحة الإدارة | `admin.html` |
| من نحن / نصائح الشراء الآمن / شروط الاستخدام / سياسة الخصوصية / اتصل بنا | `about.html` · `safety.html` · `terms.html` · `privacy.html` · `contact.html` |

الملفات المشتركة: `styles.css` (نظام التصميم)، `app.js` (التفاعلات)، `data.js` (المحافظات والماركات وسنوات الصنع)، `icons.svg` (الأيقونات).

## التشغيل

يحتاج Python 3 فقط:

```bash
python serve.py
```

ثم افتح:

- على الكمبيوتر: `http://localhost:8767/design/index.html`
- على الموبايل (نفس شبكة الواي فاي): `http://<عنوان-الكمبيوتر>:8767/design/index.html`

## ملاحظات

- التصميم **Mobile-First** واتجاه RTL، ويعمل بدون مكتبات خارجية.
- الصور في النماذج رسومات بديلة، وتُستبدل بصور WebP حقيقية في الموقع الفعلي.
- الخطوط تُحمَّل من Google Fonts مؤقتاً في النماذج فقط؛ في الموقع الفعلي تُستضاف محلياً.
- الأسعار وأرقام المحافظ في صفحة الباقات تجريبية.
